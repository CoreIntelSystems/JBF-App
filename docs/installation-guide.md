# Installation guide

The app runs on Android phones (Android 7.0 or newer). It works fully
offline: all data is stored on the phone in an encrypted database.

## 1. Download the app

1. On the phone, open the latest test build link you were sent (a GitHub
   release page named **Test build N**).
2. Tap the file ending in `.apk` (for example `jbf-app-test-12.apk`) to
   download it.

## 2. Install it

1. Open the downloaded file from the notification or the **Files /
   Downloads** app.
2. If Android asks, allow your browser or Files app to **install unknown
   apps**, then go back and tap **Install**.
3. If Google Play Protect warns that the app is unknown, tap **More
   details > Install anyway**. Test builds are not on the Play Store yet.

Newer test builds install over the old one and keep your data. Never
uninstall the app unless you have a backup: uninstalling deletes the data.

## 3. First start

There are two ways to start on a new phone:

- **New association phone (main phone):** fill in your name, a username
  and a password, then tap **Create account**. You become the Super
  Administrator. You can add a PIN and fingerprint later under
  **More > My login and security**.
- **Moving to a new phone, or setting up a field phone:** tap **New phone?
  Restore from a backup**, choose the `.jbf` backup file and enter its
  password. The app closes; open it again and sign in with the same
  usernames as on the old phone. See the
  [backup and restore guide](backup-restore-guide.md).

## 4. Allow notifications and camera

- **Notifications** are used for the monthly dues day reminder and for
  meeting and event reminders. Android asks the first time you turn a
  reminder on.
- **Camera** is used to scan member ID cards at events and meetings.
  Android asks the first time you open the scanner.

If you said no by mistake, allow them in **Settings > Apps > June Borns
Family > Permissions**.

## 5. Recommended phone settings

- Keep a screen lock (PIN or fingerprint) on the phone.
- Turn off battery optimisation for the app if reminders do not show
  (Settings > Apps > June Borns Family > Battery > Unrestricted).
